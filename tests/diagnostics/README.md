# Diagnostics métier

Ce dossier contient les scénarios de validation fonctionnelle de l'agent.

Contrairement aux tests unitaires, ces diagnostics vérifient des chaînes
de traitement métier plus larges.

## Périmètre

Les diagnostics couvrent notamment :

- la classification des intentions ;
- la détection des scénarios ;
- l'extraction structurée ;
- la résolution des dates et périodes ;
- la recherche de projets ;
- la résolution des projets ;
- la recherche des feuilles de temps ;
- la résolution des feuilles de temps.
